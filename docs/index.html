Extending the CMU Web Template

The Carnegie Mellon Web Kit builds on Carnegie Mellon's web template, for Cascade sites and the web apps that use it.

Install the Kit Get Started

Get Started

The kit is two stylesheets and a script that go after CMU's template. Start from what you're building:

Cascade site editors Add It to Your Site Paste one line into your site's head block, then use the components in any content section. Set Up a Cascade Site App developers Build an App That Matches Install a release in a Node app, or copy its files into any other stack, then use the app components. Set Up an App Designers Try an Idea Link the kit straight from the CDN in a mockup or a one-off page, and see it in a browser right away. Start a Prototype
