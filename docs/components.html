Components

Three sets, from what CMU's template already gives you to what only apps need. Start with the first: use the kit only where the template has nothing.

CMU Standard What CMU's template already has: buttons, sidebar boxes, colors, grids, feature sections, and more. Nothing here needs the kit. See CMU Standard CMS Components For Cascade pages and apps alike: a hero card, path cards, numbered steps, callouts, questions and answers. See CMS Components App Components For web apps: tabs, dialogs, file drop zones, filters, tables with actions, Load More, and pages. See App Components
