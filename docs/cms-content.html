Content Blocks

Blocks for the body of a page: path cards, how it works, steps, check lists, callouts, questions, text with a screenshot, and code blocks with a copy button.

Path Cards

Whole-card links that send each audience to its own page. They fit as many columns as the width allows; cmu-paths--two keeps a pair side by side. The cta line is the template's own.

Check List

A list of points or tips, each with a red check mark. Start each item with a short bold phrase.

ul.cmu-checks

  • Borrowing for a class? Give the course number, and you can keep it for a week.
  • Late returns pause your borrowing until the equipment is back.

Callout and Note

A callout is a labeled aside on a page, with roomy spacing: the label sits beside the text when there's space. A note is a plainer tinted box for a message among other content, such as in an app.

Code Block

Code or an address for people to read or copy, on a light gray box. Long lines scroll sideways, which keeps code's line breaks where they belong; add cmu-snippet--wrap when the whole of each line has to stay in view, such as a long address someone will copy. Put the text inside <code>, and write &lt; for each < in HTML.

pre.cmu-snippet, cmu-snippet--wrap

Copy Button

A button under a code block that copies it, for an address or markup people will paste somewhere else. Give the block an id and point the button's data-cmu-copy at it. It needs cmu-app.js.

  • Under the block, so people see what they'll copy before they copy it.
  • Name what it copies: "Copy Address", "Copy HTML", not just "Copy", and never an icon alone.
  • It says it worked. The button reads "Copied" for two seconds, and screen readers hear "Copied."
  • Without the clipboard (a page on plain http, or an old browser), it selects the text instead and says which keys copy it.

data-cmu-copy, cmu-snippet, btn
