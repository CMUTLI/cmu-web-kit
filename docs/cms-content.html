Content Blocks

Blocks for the body of a page: path cards, how it works, steps, check lists, callouts, questions, text with a screenshot, and code blocks with a copy button.

Path Cards

Whole-card links that send each audience to its own page. They fit as many columns as the width allows; cmu-paths--two keeps a pair side by side. The cta line is the template's own.

Bullet and Check Lists

For describing things (the parts of a component, the options there are), use the template's own list: a plain <ul> with no class, which gets gray open circles. Use check marks for a list of dos and don'ts, or of things you get, such as what a kit includes; when every list is checked, a page reads like a to-do list. Either way, start each item with a short bold phrase when it helps people scan.

ul, ul.cmu-checks

  • Borrowing for a class? Give the course number, and you can keep it for a week.
  • Late returns pause your borrowing until the equipment is back.

Every camera kit includes:

  • A camera body with a zoom lens
  • Two batteries and a charger
  • A tripod and a carrying case

Callout and Note

A callout is a labeled aside on a page, with roomy spacing: the label sits beside the text when there's space. A note is a plainer tinted box for a message among other content, such as in an app.

Question Teasers

A few common questions and short answers in columns, usually followed by a link to the full FAQ.

cmu-qa

Who can see my question?

Only your course's staff. Other students see just how many are ahead of them.

Can I leave the queue?

Yes, at any time. Your place goes to the next person.

Testimonial

A quote from a student, alumnus, or colleague, with their name, their role, and a square photo beside it, as on CMU Global's and Dietrich College's home pages. Put it in its own section on a color, such as content wide grey. On phones the photo goes above the quote.

  • Quote real people, with their permission, and keep it to a sentence or two. Quotation marks around the words are optional; the red mark already says it's a quote.
  • Put their name in <strong> inside the <cite>, then their role or class on the next line.
  • Describe the person in the photo's alt, not the quote. Use a square photo; the kit crops other shapes to a square.

cmu-testimonial, content wide grey

Embedded Page

A page from another site shown in a frame, such as a dashboard or a form, as on Environment at CMU's Campus Environmental Sustainability Dashboard. Give the <iframe> the cmu-embed class, and it fills its column at any screen size; set its height in the height attribute, tall enough for what's in it. The template sizes YouTube and other video frames itself (see Videos), but no others.

  • Give it a title that names what's in it: screen readers announce it for the frame.
  • Link to it below, as an ordinary external link, for people who'd rather open it in a tab of its own, and for phones, where a tall frame is hard to scroll.
  • Add loading="lazy" so it loads only when someone scrolls to it.
  • Set height to a number of pixels, such as height="700", with no units or CSS in it. Leave out frameborder and scrolling, which are obsolete; the class handles the border and the width.
  • Embed only pages that allow it. Many sites forbid being framed, and the frame then stays blank; check it on a test page first.

cmu-embed

Open the energy dashboard on its own page

Code Block

Code or an address for people to read or copy, on a light gray box. Long lines scroll sideways, which keeps code's line breaks where they belong; add cmu-snippet--wrap when the whole of each line has to stay in view, such as a long address someone will copy. Put the text inside <code>, and write &lt; for each < in HTML.

pre.cmu-snippet, cmu-snippet--wrap

<link href="https://cdn.jsdelivr.net/gh/CMUTLI/cmu-web-kit@0.1.0/css/cmu-cms.css" rel="stylesheet">
https://www.cmu.edu/example/a-long-address-that-should-stay-in-view?with=parameters&and=more-of-them

Copy Button

A button under a code block that copies it, for an address or markup people will paste somewhere else. Give the block an id and point the button's data-cmu-copy at it. It needs cmu-app.js.

  • Under the block, so people see what they'll copy before they copy it.
  • Name what it copies: "Copy Address", "Copy HTML", not just "Copy", and never an icon alone.
  • It says it worked. The button reads "Copied" for two seconds, and screen readers hear "Copied."
  • Without the clipboard (a page on plain http, or an old browser), it selects the text instead and says which keys copy it.

data-cmu-copy, cmu-snippet, btn
