Page Setup and Forms

Put cmu-app on <body> on pages with the CMU header and footer, or cmu-framed on pages shown inside another tool (such as a Canvas LTI frame) without them. cmu-app also styles forms: full-width text boxes and menus, unbulleted lists of checkboxes, and labels beside their boxes. Add inline to a text box or menu to keep its natural width.

Dialog and File Drop Zone

Use the native <dialog> element with showModal(); the browser handles focus, Escape and the backdrop. The drop zone is a label wrapping a file input, so it works by click and keyboard as well as by dragging.

cmu-dialog, cmu-dialog-buttons, cmu-drop, cmu-drop-pick, cmu-drop-file

Your script sets these on the drop zone: cmu-drop-over while a file is dragged over it, and cmu-drop-has-file once a file is chosen, with the file's name in cmu-drop-file. Inside the dialog, the hidden attribute works on anything, including buttons.

Tables With Actions

The bulk bar sits on top of a table.alternate: the selection count, then actions for the selected rows. Its height is fixed, so buttons appearing don't push the table down. Row buttons repeat the bulk bar's actions in each row, with the same words, at one fixed width and the height of a two-line button, so rows stay even. Pairs stack below 1200px.

cmu-bulk-bar, cmu-selection-count, cmu-has-selection, cmu-select-cell, cmu-sort, cmu-sort-arrow, cmu-fit, cmu-row-buttons, num

  • Selection: your script adds cmu-has-selection to the count when anything is selected, and shows the bulk buttons by removing hidden.
  • Checkbox cells: the label fills the cell, so the whole cell is the click target.
  • Sorting: put data-sort-key on the header and a button.cmu-sort inside it; set aria-sort on the sorted column.
  • Filtering: move hidden rows to the end of the table body, so the template's stripes stay even.
  • cmu-fit shrinks a column to its content. num (on th and td) right-aligns numbers.
  • Keep labels together with &nbsp;, so "a" never ends a line inside a button.

Account Link in the Header

Your name (or Sign In) in the template's red bar, beside the menu button, and again in the menu. The bar's copy hides when the menu opens and below 768px, where the menu has it instead. Signed out, it looks like the template's header links. Signed in, add cmu-account-open: it's plain text that opens the menu.

cmu-account, cmu-account-open, cmu-account-menu, cmu-account-name

<!-- In .roof, after the wordmark. Signed out: -->
<a class="cmu-account" href="/login">Sign In</a>
<!-- Signed in: -->
<a class="cmu-account cmu-account-open" href="#nav" aria-label="Account menu for Jane Doe"
   onclick="document.querySelector('.roof .menu-btn').click(); return false;">Jane Doe</a>

<!-- First item in nav#nav > ul. The template shows li.secondary only in the menu.
     An <a> without href gets the menu's spacing but isn't a link. -->
<li class="secondary right cmu-account-menu">
  <a class="cmu-account-name">Jane Doe</a>
  <a href="/logout">Sign Out</a>
</li>
