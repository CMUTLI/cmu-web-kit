Eyebrow, Lead and Call-to-Action Row

An eyebrow is a short red line above a heading. A lead is the larger first paragraph under a page title. The call-to-action row lines up a button, a link and an optional note.

Numbered Steps

Instructions to follow in order, with the step numbers in red circles.

  1. Go to the site, sign in, and select My Courses.
  2. Pick the semester from the tabs at the top.
  3. Select Upload Syllabus in a section's row.

Check List

A list of points or tips, each with a red check mark. Start each item with a short bold phrase.

ul.cmu-checks

  • File types: any document up to 20 MB, such as a PDF or Word file.

Callout and Note

A callout is a labeled aside on a page, with roomy spacing: the label sits beside the text when there's space. A note is a plainer tinted box for a message among other content, such as in an app.

cmu-callout with cmu-label, cmu-note

When to add it

Before the first day of class. Students look for syllabi as they choose their courses.

You aren't listed as teaching any sections this semester.

Question Teasers

cmu-qa

Who can see the syllabi?

Anyone with an Andrew ID can sign in to view them.

Can I replace my syllabus?

Yes, at any time. The newest one replaces the old.

Pills

A short status label. Gray unless given a tone: green for done or available, amber for waiting or missing. Amber, never red: a missing item isn't an error. Pills stay on one line, except in app tables below 1200px.

cmu-pill, cmu-pill--green, cmu-pill--amber

Tables

Use the template's table.alternate for striped rows. Add cmu-full to stretch a table to full width from 768px up (below that, the template lets it scroll sideways). cmu-compare splits a two-column table evenly, for before-and-after comparisons.
